# Amazon Clone

A simple **Amazon.in homepage clone** built using **HTML5** and **CSS3** for practice and learning purposes.

> **Note:** This project was created only for educational and practice purposes. It is **not** affiliated with or endorsed by Amazon.

## 🚀 Features

* Responsive navigation bar
* Search bar UI
* Hero banner section
* Product cards and categories
* Footer similar to Amazon
* Clean and organized HTML & CSS code
* Beginner-friendly project structure

## 🛠️ Technologies Used

* HTML5
* CSS3

## 📂 Project Structure

```text
Amazon-Clone/
│── index.html
│── style.css
│── images/
└── README.md
```

## 🎯 Purpose

The main goal of this project was to:

* Practice HTML structure.
* Improve CSS styling skills.
* Understand page layouts using Flexbox.
* Learn how real-world e-commerce websites are designed.
